# Upcoming program-session calendar export

Members can download all of an active program enrollment's upcoming, **confirmed reservations** as a single standard `.ics` file from My Programs. This builds on the existing shared RFC 5545 event renderer and individual program-session calendar links. It is a manual snapshot, **not** a live subscription, a new meeting, a payment or an attempt to reserve proposed appointment dates. When a schedule changes, members should re-export the file.

The private `GET /api/program-enrollments/[id]/calendar` endpoint uses `programActor()` to read the current session's database identity, then loads the enrollment with **both** its ID and `userId: actor.id`. A logged-in administrator, assigned practitioner or another member cannot fetch someone else's combined calendar. Errors and 404s use private/no-store headers. There is no URL-controlled account selector.

For an active enrollment, it selects future `ProgramSession.status=SCHEDULED` rows in deterministic order. Proposed sessions are suggestions, not appointments; cancelled, completed and past reservations are excluded. If the enrollment is paused, completed or cancelled, the feed contains no events. A legitimate owner without future reservations receives a valid empty calendar. Each exported event retains the stable `program-<session id>` UID already used in the individual download, actual time/duration, last update, program title, session number and current practitioner. Only HTTPS meeting URLs accepted by the existing safe-link renderer appear in the file.

The route fetches at most 101 rows and returns HTTP 413 if more than 100 confirmed future appointments exist rather than silently making an incomplete calendar. It does not change billing, enrollment schedules, reservations or notification delivery. My Programs shows the bulk download only for active member-owned program cards with at least one saved scheduled session, while staff workspaces keep their existing per-session controls.

Validation includes owner isolation, staff/administrator non-owner denial, chronological future-only export, cancellation/past filtering, paused-program behavior, a member UI download link and a browser-program scheduling journey. No database migration or provider secret is required. Roll back by reverting the new endpoint, optional My Programs link, tests and this document without touching existing sessions or individual-event exports.
